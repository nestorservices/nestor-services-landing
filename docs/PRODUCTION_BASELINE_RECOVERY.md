# Production Baseline Recovery

This source baseline was recovered from Vercel deployment
`dpl_UgFajZKQnYcXmYedWzgvTXoE3pdX` for Nestor Services. The deployment's
original Git commit could not be established, so this recovery does not claim
to restore the original commit history.

All 70 files in the deployment manifest were recovered and checked against
their manifest identifiers. A clean `npm ci` and `npm run build` succeeded;
the generated 30 public build files matched the live production files at the
time of verification.
